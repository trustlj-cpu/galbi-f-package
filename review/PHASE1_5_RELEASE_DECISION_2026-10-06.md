# PHASE 1.5 RELEASE DECISION (Claude Code · 2026-10-06) — DISPLAY QA 규칙 동결

[RELEASE DECISION]
**B.** G3 exact-zero를 VISUAL WARNING으로 강등하고 지금 REST 렌더를 만든다.

[WHY]
- 68픽셀은 1920×1080의 0.003%다. G3의 목적은 "인공 경계가 눈에 띄지 않게"라는 **지각 기준**이고, 그 판정은 원래 HUMAN GATE 5항목 중 ④("프레임 안에 인공 닫힘 변 없음")가 담당한다. exact-zero는 그 지각 기준을 픽셀 수로 과도하게 번역한 **내 과잉 명세**였다. 픽셀 수가 0이어도 사람 눈에 띄는 변이 있을 수 있고, 68이어도 안 보일 수 있다 — 결정은 사람이 화면에서 내려야 한다.
- 이 단계의 산출물은 최종 의료 일러스트가 아니라 **결정론적 구조 가이드**다. 가이드 품질은 혀·구개·입술의 관계와 타이밍에서 나오지, 턱 밑 68픽셀에서 나오지 않는다.
- A(추가 수정)를 택하면 "표시 기하 미세 조정 금지" 원칙을 또 어기고 amendment 루프가 이어진다. 68픽셀은 이미 승인된 JAW 연장으로 290→68까지 줄었고, 그 이상은 사람이 보고 결정할 영역이다.

[FINAL PHASE 1.5 RULE] (동결 — 이후 PHASE에서 변경 금지)
- G3 hard blocker: **NO.** 사전 검사는 그대로 실행하되 결과(노출 VIRTUAL 픽셀 수, 위치 썸네일)를 **보고서에 WARNING으로 기록**만 한다. 렌더를 막지 않는다.
- Blender render allowed now: **YES.** `-b`로 REST 플랫 렌더 1장 + 성도 오버레이 시트 1장 즉시 생성.
